# Reference material

The source material this build was made against. Nothing here is imported by the
application - it is kept so the log-sheet layout and the HOS numbers can be checked
against the originals.

| File | What it is |
| --- | --- |
| `assessment-brief.docx` | The take-home brief: the deliverables, the grading signals and the named outputs (route instructions, a map with stops and rests, drawn daily log sheets). |
| `fmcsa-drivers-guide-to-hos.pdf` | FMCSA's *Interstate Truck Driver's Guide to Hours of Service*. The source for the 49 CFR 395.3 limits and the eleven 395.8(d) log-sheet elements. |
| `logbook-how-to-guide-transcript.txt` | A transcript of a Schneider driver-instructor walking through a paper logbook. This is where the grid layout, the remark flags and the 70-hour recap come from. |
